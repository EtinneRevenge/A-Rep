1) OPTIONS используется для описания параметров соединения с ресурсом, например определение разрешенных сервером методов запроса, ответ на этот OPTIONS запрос будет содержать Allow заголовок с поддерживаемыми методами. Также отправка придварительного запроса по технологии CORS, например заголовок ответа Access-Control-Allow-Headers используется в ответ на preflight запрос, чтобы указать, какие заголовки HTTP могут использоваться во время фактического запроса.

2) Ключевой особенностью HTTP 3.0 является использование протокола QUIC (работающего поверх UDP), который обеспечивает быструю скорость соединения так как заранне включает в себя TLS и не требует дополнительных циклов приема-передачи, также во время мультиплесирования, QUIC обноружив потерю, востанавливает пакеты для отдельных потоков не преостанавливая работу. Использует QPACK для сжатия заголовков. Также QUIC Использует индификатор соединения CID, что позволяет не тратить время на перезапуск соединения при смене сети.
